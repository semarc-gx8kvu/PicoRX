G3ZBU mods to 'tft' branch of Jon Dawson's PicoRX. 7th March 2026

=================================================================

On Windows 10 PC I, as admin, installed WSL Ububtu.

Using WSL, do these:
	
	sudo apt install -y git cmake gcc cmake gcc=arm-none-eabi build-essential libnewlib-arm-noeabi python3
	git clone https://github.com/raspberrypi/pico-sdk.git
	cd pico-sdk
	git submodule update --init
	echo 'export PICO_SDK_PATH=$HOME/pico-sdk' >> ~/.bashrc
	source ~/.bashrc
	cd ~
	git clone --recursive https://github.com/dawsonjon/PicoRX.git
	cd PicoRX/
	git branch -a
	git checkout tft
	git submodule update --init --recursive
	mkdir build
	cd build
	cmake -DPICO_BOARD=pico ..

You will see errors!
	

I had to manually git clone no-OS-FatFS-SD-SDIO-SPI-RPi-Pico into the external subdirectory.

	cd external
	git clone https://github.com/carlk3/no-OS-FatFS-SD-SDIO-RPi-Pico.git
	git clone https://github.com/carlk3/no-OS-FatFS.git

Then repeat the last few instructions for cmake. There will still be errors so the two CMakeLists.txt
files will need a few mods, see below! Then repeat cmake   

I also added a link to f_util.h but that may be superfluous...
	ln -s include/f_util.h f_util.h

Finally you should be able to do this, from root directory:

	cd PicoRX
	./build_all 
I got errors with the Pico2/RiscV build but ignored them.
You can edit the software then 
	
	cd build
	make

or make j 4 to use 4 cores.

Press the white reset button down, connect the Pico's USB port to a PC, then release the button.
Copy the file build/picorx.uf2 into your Pico. It should run!
